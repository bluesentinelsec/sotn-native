# Bat Echo component

The core reconstructs the original Echo controller and its seventeen wave/color
drivers and thirty-two untextured strips. [Selected playable Echo](player-echo-of-bat.md)
now connects actual factory, primitive, attack and rendering ownership. The
comparisons below retain their component-only scope.

The caller must report a real forty-nine-primitive allocation. Exhaustion retains
the original sound request and retires the child without creating an attack.
Private shape/color tables and SDK quarter-wave trigonometry drive the geometry.
Facing and priority remain captured from birth; player position and rotation
remain live. Preserve signed-word angles, signed-floor arithmetic, segment widths,
color ramps and the original quarter-add blend mode.

Force of Echo is sampled at birth. It requests spell ten and extends the wave's
intensity/lifetime; toggling the relic later changes neither. The strict rising
threshold disables the attack before the fade. A real nonzero retirement request
hides the strips without advancing their geometry and decrements the original
word timer. Losing Bat form alone is not a manufactured retirement request.

Public authored tests cover normal/Force lifetimes, facing, retained birth state,
allocation failure, cancellation and atomic invalid-input failures. Private muted
LLDB runs compare 288 controlled lifetimes and 3,984 complete controller/driver/
packet records against original instructions. Original SDK trigonometry and
private shape/color tables execute; allocation, sound, spell initialization and
destruction use explicit adapters. Debug and ASan/UBSan traces are identical.
These are component comparisons, not live allocation/combat or console parity.
All original inputs and traces remain private.
