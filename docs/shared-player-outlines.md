# Shared native player outlines

The native shared effect owner now accepts actual entity31 children from private
factory blueprints. Each child retains its full parameter and generation, reserves
one real stage primitive row, follows the current normal artwork and renders its
copied outline packet through the existing ordered player-effect renderer. The
[selected Dark Metamorphosis producer](player-dark-metamorphosis.md) now runs;
MP-refill/curse and other spell producers remain unwired. The earlier internal
factory fixtures remain separate from playable casting evidence.

The original Dark Metamorphosis outline blueprint emits six children over time,
with distinct full parameters and lifetimes. Preserve all six actual owners; they
are not duplicates merely because their high-byte profile matches. Allocation
uses the same actual child masks and stage primitive capacity as other selected
abilities. Exhaustion retires the optional outline without replacing another actor
or manufacturing readiness. Room/camera changes translate retained packets and
captured sources without advancing effects. Late malformed data preserves the
runtime/character transaction. Stage commits validate lifecycle/profile identity
before publishing row leases and retire every outline row with its real child.

The real decoded body texture is already uploaded by the native presentation
owner before child updates/drawing. Existing packet priority, clipping and color
rendering now consume the outline's actual primitive. Successful child updates
request the actual player afterimage reset after player capture/presentation.
Repeated drawing does not advance phase, scale, brightness or timers.

Selected original drawing pivots now remain in player state: Gravity Boots ceiling
crunch retains (0,2), active Bat clears Y after its original return gate, stone
wiggles retain their selected pivot through recovery, and physical death clears
both. Room rebases never reset them. Normal outline births capture those values.
The current owner supplies the supported unit body scale and normal palette;
Secret Boots scaling, hidden Hellfire presentation and other unintegrated body
transform producers still need their actual contexts before those features run.
The [outline component](player-outline.md) retains its broader supplied-context
SDK comparisons; they do not prove those missing native producers.

Public authored checks cover factory/child birth, full parameter/profile identity,
real lease commit/retirement, unrelated actor protection, exhaustion, no-tick rebases,
malformed-profile rollback and selected retained-pivot recovery. Private muted native
Step/Draw and actual CMake-executable checks exercise the original six-child blueprint,
six distinct generations/rows, 882 contributed pixels, actual afterimage resets,
ordinary movement, unchanged MP and full cleanup. They use an explicit outline
factory fixture with ordinary development stats/enemies; no relic, position,
protection, stat or HP/MP grants and no save writes. Debug and ASan/UBSan pass.
A separate comparison matches 15,840 original Gravity Boots controller contexts,
including retained pivots, low/late ceilings and signed timer wrap. Factory/shake/
sound use explicit boundary adapters; Debug and ASan traces match. This is not a
spell cast, healing, full-frame, uninterrupted route or console comparison.

Ordinary starts and version-nine saves remain unchanged. Next work must connect
remaining spell controllers, MP/learning, palettes and combat/healing before
enabling further commands. Selected Dark now connects those owners. Full Alucard/shared factory/GPU and game parity remain incomplete.
