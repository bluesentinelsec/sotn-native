# Alucard sword command and recovery

An owned Alucard sword now accepts its original ground quarter-circle-forward
command in either hand. The native owner reserves the actual shared factory
before accepting the cast, charges the private virtual197 definition's five MP,
selects state15/animationD9 and requests outline20. The player stays in place
with hidden palette810D while a separate actual slot16 image moves out and back.
This adds one handled state to the [control inventory](player-control-audit.md);
26 of the original 34 states now dispatch. Milestone 1 remains open.

The exact-direction command retains its captured facing and signed-word timers.
An attack in cramped space or off the ground does not select this special.
Insufficient MP follows the original ordinary attack fallback; exhaustion of all
eight actual factory slots accepts no special and charges no MP. Exactly five MP
works. Curse keeps its existing failure path. Virtual197 is never equippable,
granted or added to ordinary saves. Ordinary starts retain their existing gear
and resources, including the default 20 MP development profile.

## Actual entity and resource ownership

Private blueprint54 performs its original forced slot16 replacement through the
shared runtime. It never allocates a second weapon/effect pool. Image birth has
no movement. The original pose5/timer1 boundary reverses facing and requests
weapon factory62; its strike child starts on the next factory pass. Pose14
reverses the image again and selects the return velocity without moving on that
boundary. Pose19 retires the real image. Signed fixed-point movement, damping,
full fractions and whole-word wrapping retain their original order. Room rebases
translate retained images and sources without advancing either controller.

The strike borrows its actual parent's generation and virtual equipment identity,
keeps that lineage separate from retained Bat/Wolf transformation generations,
uses the private weapon43 animation and sprite bank, and applies native combat
metadata and enemy damage. Hitbox height observes the preceding animation frame;
its birth is inactive. Swishes follow the independent child pose. One original
libc RNG call computes critical metadata at actual strike birth; failed or
exhausted optional factories consume none. Attack applies original signed-word
body/buff bonuses before caps, then poison, and uses the original SDK whole root.
The least-used group counter increments before the original parent enemyId0
copy; end-of-pass recount drops that transient increment. Group0 has its own
retained enemy cooldown, shared by both hands' strikes and preserved across births.

Native rendering uses the actual resident player image for the moving body and
private weapon artwork for the strike. These are sprite entities with no primitive
leases. Only outlines20/21 reserve real shared rows; optional exhaustion omits
the outline without delaying control recovery. The full low parameter words and
three scheduled children per original outline blueprint remain distinct owners.

Supported owned hand changes retain the already accepted virtual197 strike.
The native renderer temporarily binds the real weapon43 artwork for that entity,
then restores the selected hand overlay. This bounded immutable-resource binding
preserves the native owner's presentation when a menu selection changes the hand;
it is not a claim of complete original GPU/overlay contention or console parity.

## Player recovery and clock boundaries

State15 waits for actual slot16 retirement. It then requests outline21 and starts
the original 32-bit sixteen-update counter. Expiry restores normal palette8100
and the original standing/ledge helper. The native session refreshes the actual
factory callback and slot context after replacement; no readiness timer replaces
the entity handshake. Ordinary HUD MP recovery retains its actual gameplay-clock
cadence during the move, independently of the cast's five-MP cost.

Menus, maps, spell freeze and draws hold the player, command, image, strike and
recovery owners. Repeated drawing advances no controller, lifetime or RNG.
Only actual flagged effects follow the existing frozen dispatcher. Runtime and
character copies commit after successful shared updates; late player failures
undo the actual root/outline factory reservations. No default grants, save fields
or version-nine format changes are introduced.

## Evidence and remaining work

Authored public regressions cover both hands, command expiry, signed wrap,
private animation end handling, parent/slot lifetime, retained equipment,
exact/insufficient MP, curse, real factory exhaustion, malformed-image rollback,
frozen/no-tick holds, malformed factory ranges and sixteen-update recovery. Native enemy tests cover
shared group0 cooldown across both hands/replacement generations and its
independence from an ordinary left-hand attack.

Private instruction comparisons match 14,112 image-motion contexts, 3,072 QCF
contexts, 1,212 strike/callback/private-animation contexts, 3,200 original virtual197
attack/critical/stat contexts, 256 original state15 recovery contexts and
144 outer status-construction contexts. Debug and ASan traces are identical.
Factory/destruction, selected metadata, RNG, equipment-count and SDK CLZ services
use explicit adapters where recorded. These isolate original algorithms; they
are not complete original frame/collision or console comparisons.

Muted LLDB checks use the default Entrance room0 gear and resources, ordinary
commands, actual image/strike/outline generations, visible body/strike contribution,
real menu/map holds, a supported owned-hand selection, restored jumping and actual
late-player-failure reservation rollback followed by a successful retry. A real
spawned/positioned breakable supplies separate native combat evidence. The actual
CMake-built app also runs the command, cost, entities, outlines and recovery and
quits normally through SDL. Explicit starts, target positions, equipment selections
and malformed-image copies are not acquisition, uninterrupted-route or console
proof. Full platform/sanitizer results are recorded with the feature PR.
