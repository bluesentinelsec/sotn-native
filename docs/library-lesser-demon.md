# Selected Lesser Demon body

The native Library service now runs Lesser Demon's body AI, attack children,
windups, summoning and physical defeat. The [placed arena flow](library-demon-entry.md)
now adds entry, sealing books, camera unlock, music, the ordinary defeat record and
reward. The body-only evidence below remains separate from that newer integration
check. Stage 2 remains disconnected pending shop interaction and remaining scripts.

The body retains grounding/activation waits, pose-driven ground displacement,
wall/floor decisions, boundary leaps, flight/hover, dive/swipe, spit, bolt and
summoning choices. Screen-coordinate decisions remain distinct from room-world
constraints. Private animation, motion, sensor and wait tables stay in runtime
data. Original random draws retain their order, including allocation-dependent
draws and optional exhausted actor pools.

The swipe uses a generation-owned hitbox and the original five gray-puff factory.
Its quad changes palette, dimensions and brightness before releasing its pair.
The bolt star retains its private SDK matrix rotation and column-scale rounding.
Spit windup draws twenty-four colored attraction tiles with original timing,
visibility and fixed-point velocities. Existing spit/bolt services then run
independently; read [attack scope](library-demon-attacks.md), including the explicit
US initial bolt-vertex safety adaptation. [Selected poison mechanics](player-poison.md) now run; full status effects remain pending.

Summoning retains its temporary HP hold, saved-HP restoration, palette cadence,
thirty colored packets and original minion selection. Rainbow rows remain private.
Packet iteration, same-update child creation, reuse colors, side-dependent blending,
widening/closing and allocation-dependent RNG remain explicit. The original second
color profile is unused by this selected function; both source branches use the
first profile. [Mudman, Skeleton and Ectoplasm](library-minions.md) retain their own
appearance, combat and boss-cleanup behavior.

Physical defeat releases the current effect reservation, disables contacts, removes
summoned minions, falls/lands, runs selected flames/animation and fades before setting
the original completion signal. Complete hit palettes/outlines, elemental effects,
full poison effects, full sound/reverb and audiovisual/timing parity remain incomplete.

Public synthetic cases cover activation, ground/air decisions, leaps, swipe ownership,
projectile release, temporary HP, minion selection, column propagation/colors, pool
exhaustion, RNG preservation, death signals and malformed data. A private comparison
matches 40,000 scaled effect-quad cases against the pinned SDK algorithm with the
user's original matrix-pair table. It checks signed rounding and screen saturation;
it is not a general GTE or complete console comparison.

All 68 public groups pass in Debug and macOS ASan/UBSan; release packaging passes.
A private LLDB fixture inserts the body at its original reserved slot in room 0,
activates it explicitly and uses a protected 9000-HP/strength-99 character. Movement
keeps a useful distance until the original AI has selected dive, spit, bolt and
summoning and produced a minion; ordinary combat inputs then defeat it. Debug and
ASan/UBSan agree at tick 3963, 991 renders and 243 observed death ticks, and exit
successfully. Earlier stationary/range-limited probes did not exercise every attack
and are not counted as a completed fight. This fixture does not establish placed
entry/reward, an uninterrupted route, an unmodified-character playtest or console parity.
