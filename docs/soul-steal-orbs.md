# Soul Steal orb ownership

The selected ordinary US stage orb now runs as actual common actor seven with one
row in the shared stage primitive pool. The
[playable Soul Steal owner](player-soul-steal.md) now consumes this healing-child
service. The component alone does not enable the spell command or its attack.

The controller preserves the original stage `Random` stream, signed-word angle
limits, SDK trigonometry, fixed-point fractions, speed/turn growth, private byte
animation and opaque GT4 geometry. Birth consumes one random value after successful
allocation. Row exhaustion retires the optional orb before initialization or RNG.
The private angles, shapes and animation remain borrowed from each stage overlay;
all eleven currently supported profiles use their own checked offsets.

Pickup becomes active on the sixteenth update after birth. The stage collision
owner records actual player contact even during invincibility. Contact retires the
orb and requests eight HP through the existing deferred healing owner. An already
pending heal wins; Bloodstone does not multiply orb healing. The next successful
player tick applies the heal once, with the existing sound/flash/death/stone rules.
Room rebases retain fractions and timing. The ordinary dispatcher owns contact
clearing, actor lifetime and real primitive release; the frozen dispatcher retains
its existing original flag gates.

Public tests use authored tables and cover animation, steering state, age-sixteen
contact, pending-heal precedence, real row ownership, room rebasing, malformed data
and exhaustion. A private instruction comparison checks 160 supplied contexts and
10,576 complete body/quad/animation/RNG/heal snapshots against the original US
Laboratory implementation. Allocation and destruction use explicit adapters;
SDK math, stage RNG, animation and controller instructions execute from the user's
private images. Debug and ASan/UBSan traces match byte for byte. Private table checks
cover the extents and contents of all eleven supported overlays. A muted native
LLDB check in Debug and ASan/UBSan draws the actual orb, observes its homing/contact,
heals HP50 to58 exactly once and verifies actor retirement. This uses explicit
room/position/HP/contact-protection fixtures; it writes no ordinary saves.

This is scoped component/native-child evidence. The selected spell command/global
attack have separate evidence in the playable integration above. Full shared contention, uninterrupted routes and console
presentation parity remain unproven. Alucard and the castle remain incomplete.
Saves stay version nine,
and ordinary starts grant no resources or abilities.
