# Selected playable Hellfire

Hellfire now connects the ordinary command to original casting, actual shared
factories/children/rows, private gradients and animation, player visibility,
projectile rendering, spell-two combat, MP and learning. This is a selected native
development path. Soul Steal, Sword Brothers, other remaining abilities/equipment/
familiar/water work, complete shared contention and Alucard remain unfinished.
It is not a full-game or console-parity claim.

Enter Up, Down, Down-forward, Forward, then either hand attack. Forward follows
the facing captured at Down. It costs the original 15 MP; exact-cost casts work.
Hold Up when the reappearing beam requests projectiles for the two large piercing
fireballs, otherwise it creates three normal fireballs. Up is sampled at that
request, not latched at cast birth. Down cancels at the original signal-three
attack boundary, retaining the paid cost and learned spell.

The command enters original state34 and reserves the real root factory on the
same player update. Exhaustion preserves the original normal-helper/animation/
substate fallback; a pending factory never manufactures child readiness. Native
player callbacks journal the actual eight factory records so later player-update
validation failure restores those reservations along with the uncommitted player.
There is no second factory pool. Spell learning uses the existing character state.

The beam's real signal and palette changes reach the player only after successful
stage-row commit. Hidden movement uses the original preceding floor masks, screen
edges and existing eight-pass collision, including slope scaling. Signal two stops
movement/reappears; signal three begins the attack animation. Actual pose ten/
duration one requests timer12 and the expanding circle. Animation completion or
FFFF invokes original recovery. Original finishing requests restore actual curse/
poison BlinkWhite children when their real timers remain active; they do not invent
a player-palette reset.

Both original private gradient rows upload once to the real texture owner. Draws
sample retained packets and private sprites without ticking effects or copying
substitute art. The flash is an untextured G4; the beam retains original raw GT4
semantics. Projectile/trail drawing uses actual private frames, scale, rotation,
facings and palettes. The shared runtime retains its original factory/animation/
RNG/group/row ordering and actual normal-hit retirement versus large piercing.
Full GPU/ordering-table capacity, raster/audio timing, scene interactions and
all-ability contention remain outside this selected evidence.

Ordinary starts grant no resources or abilities. Saves remain version nine and
retain learned Hellfire through the existing spell field. Transient casting,
callbacks, palette/signal and child owners are not serialized. Full stage starts
and Continue create fresh transient owners; each normal player update binds its
current session, including after session replacement. Existing user slots remain
untouched by private probes.

Public authored fixtures cover command/MP/factory integration, exact-cost and
insufficient casts, recovery/timer/circle/status-flash requests, allocation fallback,
ailment glow lifetime, gradient bounds/prevalidation and untextured rendering.
The prior components retain their separate original-instruction comparisons.
Private poison/curse comparisons add 96 supplied timer/facing/rotation/position
contexts and 6,624 complete controller/shared/packet snapshots, with matching
Debug and ASan/UBSan results. They execute original image and geometry helpers,
with explicit allocation/destruction/SDK CLZ adapters.

Native checks exercise normal/large commands, 15 MP/learning, uploaded gradient
pixels, hiding/reappearance, animated rendering, both facings, Down cancellation,
left steering across the actual Laboratory slope and live ailment glows in eight
Debug and eight sanitizer contexts. They use
explicit room-three/X124/contact-protection and ailment fixtures. Separate actual
CMake executable checks run both variants in Debug and ASan/UBSan through LLDB
and ordinary SDL quit.
Additional exact-15-MP/insufficient-14-MP, paused-owner, in-memory-v9 learning/load,
checkpoint callback rebinding and deliberately invalid copied-animation-pointer
rollback fixtures exercise lifecycle boundaries without writing user slots.
These are protected explicit checkpoints, not uninterrupted ordinary encounters,
acquisition routes or console replays. Private data/artwork/traces remain local.
