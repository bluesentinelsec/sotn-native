# Olrox skull columns

The internal BO0 encounter now advances the humanoid body's three reserved skull
columns. Original animation, four private birth delays, release command, squeeze,
seven wave radii, physical hitbox growth and retirement run independently of
presentation. Each column owns its twelve textured beam halves and twelve
framebuffer-feedback quads. Missing parent generations retire unreleased columns;
released geometry retains its independent lifetime. Optional primitive exhaustion
retires only that column.

The native renderer captures its ordered RGB555 frame before each visible
feedback command and samples an immutable owned copy through the original direct
color page identities. It preserves zero-color transparency, UV wrapping/clipping
and command priorities without overwriting artwork or retaining borrowed frame
pointers. Both original buffer pages resolve to that current native frame.
This bounded snapshot adapter does not reproduce PS1 GPU read/write aliasing or
texture-cache behavior; console pixel parity remains unproven.

## Validation and scope

Public authored tests cover all original delay indices, readiness/release timing,
wave geometry and damage bounds, full retirement, parent reuse, transition-time
early returns, primitive exhaustion and invalid resources/state/ownership.
Renderer regressions cover overlapping source/output, replacement snapshots,
both direct pages and failure before framebuffer writes.

Private checks match 10,174 original US instruction snapshots across twenty-four
sequences, including semantic hashes of every owned quad's coordinates, UV,
page, palette, priority and visibility. Original animation, RNG and SDK trig
execute; initialization, allocation/audio backends and a nonclearing retirement
observer are isolated adapters. The original draw-buffer fixture is stable.
This establishes selected command/state agreement, not console GPU or full-fight parity.

Muted native LLDB checks advance the placed introduction and natural commands
through three columns, three waves and three retirements. A draw-isolation check
measures their rendered contribution. Fixtures supply only an explicit room
arrival and contact protection, with no ongoing positions, boss state, HP,
equipment, relic or readiness grants. User saves remain untouched.

Transformation, second form, furnishings, final victory/reward and connected
BO0/NO2 travel remain incomplete. The encounter and game are not complete.
